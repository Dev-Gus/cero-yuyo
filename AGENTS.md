# Instrucciones para agentes

- Leé PROJECT.md primero.
- Trabajá únicamente en la rama `main` de este repositorio.
- Hacé un commit después de cada tarea.
- Actualizá la sección Status de PROJECT.md al terminar algo.
- Nunca leas, modifiques ni accedas a otras carpetas o repositorios. Este proyecto es independiente.
- No agregues contenido que no esté en PROJECT.md: no inventes precios, testimonios, fotos, servicios ni promesas de "próximamente".
- La tarea inicial es solo el scaffold: no desarrolles contenido ni diseño hasta que se solicite.
